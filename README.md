# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 窗起按滑动步长对齐；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 滑动窗切分（已实现）

全局唯一窗格引擎，窗起一律按**滑动步长**对齐（不用翻滚对齐冒充滑动）：

- **翻滚** = 步长等于窗长的退化滑动：窗互不重叠，每事件恰落 1 窗；
- **滑动** = 步长小于窗长（须整除）：相邻窗重叠，每事件恰落 `窗长/步长` 窗，多窗归属、整集原子；
- 窗键带窗代 `房|g代|窗起`；改窗型/改步长：有开启窗 → **失败闭**（409）；`POST /api/排水` 清场后换代，历史以旧代隔离；
- 装载/改参/排水共用互斥锁：一批事件全属同一窗代，不得半截双套窗键；同一房不得同时两代开启窗；
- 旁路取事件窗键集**最旧一扇**的旁路界，越界整事件原子旁路。

只读接口：`GET /api/窗型`（窗型/窗长/步长/窗代/每事件窗数/valid）、`GET /api/窗键集?事件时=&房间键=`（事件窗键集）。
协同接口：`POST /api/窗参`（换代）、`GET /api/窗参史`、`POST /api/排水`、`POST /api/演练/改步长并发`。

夹具：`翻滚单窗样例`（甲恰落 1 窗）、`滑动窗样例`（乙落 2 窗，窗键集可查且与步长一致）；
`backend/tests/test_滑动窗.py` 钉死口径，含改步长×入流并发核查。
